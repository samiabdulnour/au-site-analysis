Open data only

what it reads
Every drawing is made by code from data that government agencies and open projects publish for anyone to use: the NSW planning, cadastre, elevation and imagery services, the ABS, OpenStreetMap, Overture Maps and the others listed on each drawing and on How it works. Nothing is surveyed, visited or checked by a person.
as it stands
A drawing shows that data as it stood when the drawing was made. Each drawing names its sources and the date it read them.
