SITE ANALYST

Enter a NSW street address and choose a drawing. Context analysis maps the neighbourhood — zoning, transport, amenities, walkability. Site analysis maps the lot itself — boundary dimensions, levels, fall, sun path, winds, neighbours. Development summary tabulates the planning controls that apply to the lot. All are assembled from NSW planning, cadastre, transport and imagery open data. Takes 1–3 minutes.
